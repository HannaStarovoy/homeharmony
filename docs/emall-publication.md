Публикация товаров выполнена в разрабатываемом магазине. Публичного адреса магазина пока нет. Для локального просмотра запустите `npm start` и откройте `http://127.0.0.1:8000/`. Размещение приложения в интернете — отдельный этап.

## Сохранение публикации

`data/emall-publication.json` содержит отдельное решение о публикации ровно пяти внешних ID. При запуске приложения сначала загружается пакет карточек, затем решение применяется в одной транзакции. В рабочей базе перед публикацией создана локальная резервная копия. Остальные товары, заказы, пользователи, цены и остатки сохраняются.

Решение помечается как применённое в таблице `catalog_publications`. Повторный запуск не создаёт дубли, не переписывает карточки и не публикует заново товар, который владелец позже скрыл через админку. Пакет импорта по-прежнему создаёт черновики; публикация выполняется только по отдельному сохранённому решению.

В рабочей базе теперь 19 опубликованных товаров: пять настоящих Emall и прежние 14 демонстрационных. Снятие товара с витрины выполняется в `/admin` через возврат в черновик.

## Проверка

`node scripts/capture-emall-published.cjs` проверяет публичный каталог, пять реальных карточек, цены, все 13 фотографий, страницу товара и повторный запуск. Он использует временную базу и создаёт два снимка выше. В браузере выполняются только читающие запросы, заказы не создаются.

`npm test` дополнительно проверяет атомарность публикации, защиту выбранных ID и сохранение последующего ручного снятия с витрины. Всего пройден 161 серверный тест.
