# Первые пять черновиков Emall

Подготовлен импорт пяти карточек с названиями, описаниями, характеристиками, ценами, остатками и фотографиями. Реальный запуск подготовки пакета пока не выполнен: автоматическая проверка запросила явное разрешение на выгрузку данных каталога в GitHub.

Репозиторий `HannaStarovoy/homeharmony` публичный. После сохранения пакета в `data/emall-drafts/` данные карточек и фотографии будут доступны посетителям GitHub. В самом магазине карточки останутся черновиками и не попадут на витрину до публикации в админке. Ключ API, заказы, контакты покупателей и учётные записи в пакет не включаются.

## Как устроен перенос

1. Ручной workflow `.github/workflows/emall-import.yml` читает первые пять товаров через существующий `EMALL_API_TOKEN` в GitHub Secrets.
2. Категории сопоставляются с четырьмя согласованными разделами магазина. Нераспознанная категория останавливает подготовку, вместо назначения случайного раздела.
3. Цены переводятся из копеек в BYN, характеристики расшифровываются по справочникам. Один ID товара Emall создаёт один товар и один SKU; объединения вариантов не выдумываются.
4. Фотографии скачиваются отдельно без заголовка авторизации, проверяются и сохраняются в WebP. Пакет содержит локальные фотографии и нормализованные записи, без ключа и исходных URL.
5. До передачи пакет проверяется в отдельной базе: пять черновиков, отсутствие публикаций, повторное применение без дублей. Затем он сохраняется как артефакт `emall-drafts` на семь дней.
6. Проверенный пакет сохраняется в репозитории как `data/emall-drafts/manifest.json` и `data/emall-drafts/media/*.webp`. Отдельный `review.json` содержит предупреждения для проверки.
7. При обычном `npm start` магазин подхватывает пакет и создаёт карточки в SQLite как черновики. Существующие заказы, пользователи и товары сохраняются.

Неизменённый пакет при перезапуске не перезаписывает ручные правки и не создаёт дубликаты. Новая версия пакета обновляет данные из источника; ручные фотографии при таком обновлении пока не защищены от замены ссылок на фотографии источника. Непрерывная синхронизация остатков между сайтом и Emall не включена.

## Проверка в админке

После применения пакета откройте `/admin`, затем список товаров и фильтр черновиков. Перед публикацией проверьте категорию, изображения, характеристики, цену и доступное количество. Значение `stock` из Emall требует сверки: документация не уточняет для этого ответа учёт резервов маркетплейса.

Подготовка из терминала разработчика: `node scripts/prepare-emall-drafts.mjs`. Результат пишется в `var/emall-prepared/`; рабочая база магазина этой командой не изменяется. Команда предназначена для процесса, в котором настроен ключ. Облачную среду ChatGPT для запуска через GitHub настраивать не требуется.
