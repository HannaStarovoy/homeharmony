# Как запустить магазин и админку

## Просто посмотреть дизайн

Скачайте `preview.html` и откройте двойным щелчком. Стили, демокаталог и картинка уже встроены; соседние файлы не нужны. Это просмотр демотоваров без отправки заказов и админки.

Обычный `index.html` нужно открывать из полностью распакованного проекта: рядом должны лежать `storefront.css`, `catalog-data.js` и папка `assets`.

Для обновления автономного файла после изменения дизайна выполните `node scripts/build-preview.mjs`.

## 1. Скачать проект

На странице репозитория GitHub нажмите **Code → Download ZIP**, затем распакуйте архив.

Нужен **Node.js версии 24 или новее**. Установите его, если он ещё не установлен.

## 2. Открыть терминал в папке проекта

В этой папке должен находиться файл `package.json`.

Выполните по очереди:

```bash
npm ci
npm run admin:create
```

Вторая команда попросит email владельца, пароль от 12 символов и повтор пароля. При вводе символы пароля не отображаются — это нормально. Пароля по умолчанию нет.

## 3. Запустить магазин

```bash
npm start
```

Оставьте терминал открытым. В браузере **на том же компьютере** откройте:

- Магазин: `http://127.0.0.1:8000`
- Админка: `http://127.0.0.1:8000/admin`

Эти адреса работают на компьютере, где запущен сервер. Для общего доступа через интернет нужно отдельно разместить приложение на сервере с HTTPS. Загрузка кода на GitHub сама по себе сайт не запускает.

## 4. Добавить товар

1. Войдите в админку с заданными email и паролем.
2. Нажмите **«Добавить товар»**.
3. Укажите название, категорию, описание и характеристики.
4. Заполните артикул, цену и остаток. Если покупателю нужен выбор размера, цвета, объёма или упаковки, добавьте параметр и варианты.
5. Загрузите фотографии товара и, при необходимости, отдельных вариантов.
6. Нажмите **«Сохранить черновик»** или **«Опубликовать товар»**.

Черновик виден только в админке. Опубликованный товар появляется в каталоге работающего магазина. Кнопка **«Сохранить и скрыть»** возвращает его в черновик.

## Применить действие к нескольким товарам

1. В списке товаров при необходимости задайте поиск, категорию или статус, например «Черновики».
2. Отметьте товары чекбоксами слева. Верхний чекбокс выбирает все товары, найденные текущими фильтрами.
3. В панели над таблицей выберите **«Опубликовать»**, **«Вернуть в черновики»** или **«Удалить»**.
4. Нажмите **«Применить к выбранным»** и подтвердите действие. После выполнения выбор сбрасывается.

При обновлении списка, изменении поиска или фильтров выбор сбрасывается. Если один из выбранных товаров изменился в другом окне или действие для него невозможно, вся операция отменяется: сначала устраните причину и выберите товары заново. Для массового удаления действуют те же ограничения по резервам заказов.

## Удалить товар

В списке товаров нажмите **«Удалить»** или откройте карточку и нажмите **«Удалить товар»**. Подтвердите удаление в появившемся окне. Товар исчезнет из админки и витрины и не появится заново после повторного импорта Emall. История уже оформленных заказов сохранится. Если товар зарезервирован в активном заказе, сначала обработайте или отмените этот заказ.

## Повторный запуск и сохранение данных

Чтобы остановить сервер, нажмите **Ctrl+C**. Чтобы запустить снова, выполните `npm start`. Создавать владельца повторно не нужно.

Папка `var` содержит базу данных, фотографии и учётные записи. Не удаляйте её. Для резервной копии остановите сервер и скопируйте всю папку `var`.

Если забыли пароль:

```bash
npm run admin:create -- --email YOUR_EMAIL --reset
```

Замените `YOUR_EMAIL` на email существующего владельца. Команда запросит новый пароль.

## Как принимать заказы

Покупатель оформляет заказ на работающем сайте и получает номер. Заказ появится в разделе **«Заказы»** админки. Откройте карточку, проверьте состав, сумму и контакты, свяжитесь с покупателем и согласуйте оплату и доставку.

- **«Подтвердить заказ»** — оставить товары в резерве до исполнения.
- **«Отменить заказ»** — освободить резерв.
- **«Передать в доставку»** — списать товар со склада.
- **«Завершить заказ»** — отметить выдачу или завершение; повторного списания не будет.

Неподтверждённый заказ держит резерв 24 часа, затем освобождает его автоматически. У подтверждённого заказа резерв остаётся до отправки, выдачи или отмены. В редакторе товаров указывайте **физический** остаток: резерв показан отдельно.

Заказы и резервы сохраняются в базе по-настоящему. Онлайн-оплата и интеграция со службами доставки пока не подключены. Предварительные тарифы доставки — 8 BYN курьером, 6 BYN почтой, самовывоз бесплатно; перед публичным запуском согласуйте тарифы и заполните реальные сведения продавца. Подробности — в [README.md](README.md).
