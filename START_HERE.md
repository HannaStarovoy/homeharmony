# Как запустить магазин и админку

## 1. Скачать проект

На странице репозитория GitHub нажмите **Code → Download ZIP**, затем распакуйте архив.

Нужен **Node.js версии 24 или новее**. Установите его, если он ещё не установлен.

## 2. Открыть терминал в папке проекта

В этой папке должен находиться файл `package.json`.

Выполните по очереди:

```bash
npm ci
npm run admin:create
```

Вторая команда попросит email владельца, пароль от 12 символов и повтор пароля. При вводе символы пароля не отображаются — это нормально. Пароля по умолчанию нет.

## 3. Запустить магазин

```bash
npm start
```

Оставьте терминал открытым. В браузере **на том же компьютере** откройте:

- Магазин: `http://127.0.0.1:8000`
- Админка: `http://127.0.0.1:8000/admin`

Эти адреса работают на компьютере, где запущен сервер. Для общего доступа через интернет нужно отдельно разместить приложение на сервере с HTTPS. Загрузка кода на GitHub сама по себе сайт не запускает.

## 4. Добавить товар

1. Войдите в админку с заданными email и паролем.
2. Нажмите **«Добавить товар»**.
3. Укажите название, категорию, описание и характеристики.
4. Заполните артикул, цену и остаток. Если покупателю нужен выбор размера, цвета, объёма или упаковки, добавьте параметр и варианты.
5. Загрузите фотографии товара и, при необходимости, отдельных вариантов.
6. Нажмите **«Сохранить черновик»** или **«Опубликовать товар»**.

Черновик виден только в админке. Опубликованный товар появляется в каталоге работающего магазина. Кнопка **«Сохранить и скрыть»** возвращает его в черновик.

## Повторный запуск и сохранение данных

Чтобы остановить сервер, нажмите **Ctrl+C**. Чтобы запустить снова, выполните `npm start`. Создавать владельца повторно не нужно.

Папка `var` содержит базу данных, фотографии и учётные записи. Не удаляйте её. Для резервной копии остановите сервер и скопируйте всю папку `var`.

Если забыли пароль:

```bash
npm run admin:create -- --email YOUR_EMAIL --reset
```

Замените `YOUR_EMAIL` на email существующего владельца. Команда запросит новый пароль.

Оформление заказов, платежи и резервирование склада пока демонстрационные. Полные технические сведения находятся в [README.md](README.md).
